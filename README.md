# smtptest
smtptest Test send message using smtp 


# To test
- download smtptest.zip
- unzip it
- in cmd run:

```
smtptest.exe -host smtp.gmail.com -port 465 -user tucorreo@gmail.com -pwsd "tu_app_password" -to destino@ejemplo.com -msgsubj "Prueba de conexión"   -msgbody "Hola, esto es una prueba SMTP."
```
